# 1.3.1 MCU Firmware Decompilation & CAN Architecture Reference

Technical reference and decompilation documentation for the STM32F105 companion MCU firmware (`can_app.bin`) used on the Limcet Box P305/P306 CarPlay / Android Auto head unit platform.

---

## 1. Firmware Overview & Memory Architecture

- **Target MCU**: STMicroelectronics STM32F105RBT6 (ARM Cortex-M3, Connectivity Line).
- **Core Parameters**: 128 KB Flash memory (`0x08000000 - 0x08020000`), 64 KB SRAM (`0x20000000 - 0x20010000`).
- **Binary Image**: `hardware/MCU/can_app.bin` (31,996 bytes).
- **Base / Link Address**: `0x08004000`.
- **Initial Stack Pointer (SP)**: `0x20002DC0`.
- **Reset Vector**: `0x08004239` (Thumb execution starts at `0x08004238`).

### 1.1 Memory Partitioning
```
0x08000000  +---------------------------------------+
            |  Resident Bootloader (16 KB)          |
            |  - YMODEM receiver over USART2/ttyHS0 |
            |  - Flash erase & program routines     |
0x08004000  +---------------------------------------+
            |  Application Binary (can_app.bin)     |
            |  - Vector Table (0x08004000)          |
            |  - Startup & SystemInit               |
            |  - bxCAN Driver & Filter Engines      |
            |  - CAN Mode Dispatch Tables           |
            |  - UART Protocol Parser & Dispatcher  |
0x0800BD00  +---------------------------------------+
            |  Unallocated Flash (to 0x08020000)    |
0x08020000  +---------------------------------------+
```

## 3. CAN Bus Subsystem & Frame Processing

### 3.1 Reception & Ring Buffer Flow
1. **CAN1_RX0 ISR (`0x08007064`)**:
   - Reads hardware FIFO0 via `CAN_Receive()` into a 15-slot circular software ring buffer located in SRAM at `0x200002BC`.
   - Each slot is 20 bytes (`CanRxMsg` structure):
     - `+0x00`: `StdId` (uint32_t)
     - `+0x04`: `ExtId` (uint32_t)
     - `+0x08`: `IDE` (uint8_t: 0 = Standard 11-bit, 4 = Extended 29-bit)
     - `+0x09`: `RTR` (uint8_t)
     - `+0x0A`: `DLC` (uint8_t: Data Length Code)
     - `+0x0B..0x12`: `Data[0..7]` (uint8_t array)
     - `+0x13`: `FMI` (uint8_t)
   - Ring write index (`head`) is maintained at SRAM offset `0x200002BC + 0x12C`.
   - Ring read index (`tail`) is maintained at SRAM offset `0x200002BC + 0x12D`.

2. **CAN Message Dispatcher (`0x08007F04`)**:
   - Drains the circular buffer: pops the next frame when `head != tail`.
   - Determines ID (`StdId` or `ExtId` based on `IDE`).
   - Reads `mode` byte from SRAM `0x200002BC + 0x36`.
   - Iterates through the corresponding Mode Table and calls the matching handler function.
   - Forwards/relays the frame through `CAN_Transmit()` (`0x08004CD2`) onto CAN1.

## 5. UART Protocol to ARK1680 SoC (`/dev/ttyHS0`)

The MCU communicates bidirectionally with the ARK1680 SoC over USART2 configured at **38400 baud, 8N1**.

### Wire Framing Format
```
[0x2E] [CMD] [LEN] [PAYLOAD (LEN bytes)...] [CHECKSUM]
```
- Header: `0x2E`
- Command byte: Protocol command ID
- Length: Number of payload bytes
- Checksum: One's complement of byte sum (`~sum(CMD + LEN + PAYLOAD) & 0xFF`)

### Inbound UART Command Dispatch Table (`0x0800B9E4`)
| Cmd | Handler Address | Role / Behavior |
|:---:|:---:|---|
| `0x81` | `0x080088B5` | Initialization handshake ACK (resets state slots 12, 1, 8, 10). |
| `0x82` | `0x08008BD5` | Mode / Application change notification (`onModeAppChanged`). |
| `0xA0` | `0x080089D9` | General UI settings sync channel (volume, screen parameters). |
| `0xFF` | `0x080088E9` | System control & state reset helper. |
| `0xE1` | `0x080088E1` | **Reboot to Bootloader**: writes `0x5555AAAA` to SRAM `0x20004004` and spins for watchdog reset. |
| `0x85` | `0x08008BA9` | App protocol response. |
| `0x84` | `0x08008809` | Audio routing select (`AT+AUDROUTE=1/2`). |
| `0x87` | `0x080087A1` | Settings list selection / Bluetooth AT trigger. |
| `0x88` | `0x0800893D` | Timestamp / counter sync. |

## 6. How to Modify CAN Codes & Build Updates

Using the provided toolset in `tools/mcu_builder/`:

1. **Modify CAN IDs in Table**:
   - Standard Toyota Prado 150 SWC broadcast is `0x3C4`.
   - Update Mode 1 Entry 7 from `0x105` to `0x3C4` using `mcu_rebuild.py` or `can_config_template.json`.
2. **Rebuild the Firmware & Package**:
   ```bash
   ./tools/mcu_builder/build_mcu_update.sh --preset toyota_prado_150
   ```
3. **Deploy via USB**:
   - Copy `output/usb_root/auto_upgrade.txt` and `output/usb_root/can_app.bin` to the root of a FAT32 USB drive.
   - Plug into the unit to auto-flash.
